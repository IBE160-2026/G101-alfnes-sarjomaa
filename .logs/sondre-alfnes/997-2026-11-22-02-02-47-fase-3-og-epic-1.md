# Fase 3 og epic 1

## 2026-11-22 kl. 02:02 — Sondre Alfnes

### Oppgave
Gå gjennom Moduler i Canvas og oppdatere wikien, sjekke hvor langt kullet har kommet, lage en
plan og følge den, og fortsette implementeringen. Underveis: vendre ponytail og designskillene
(impeccable, taste-skill) inn i repoet og gjøre dem til faste regler, bytte dommer til
OpenRouter/DeepSeek, og pause etter story 1.5.

### Plan
- Planen er [plan-fase-3-og-4](../../wiki/prosjekt/plan-fase-3-og-4.md). Promptene ligger i `prompting/fase-3-arkitektur/` og `prompting/fase-4-implementering/`.
- Fase 3 med headless BMAD-subagenter: UX og arkitektur parallelt, så krysssjekk, impeccable-critique, epics og sprintplan.
- Fase 4: én subagent per story (`ponytail` + `bmad-build-auto`, og `impeccable` ved UI), med verifisering mellom hver story.

### Resultat
- **Wiki (main):** hele sensorveiledningen, kullstatus 21. nov., planen, og nye arbeidsregler (én branch og én PR per epic, KI committer per story, ponytail alltid på, designskills på alt UI). CLAUDE.md og hukommelsen er oppdatert.
- **Skills (main):** ponytail (6), impeccable og design-taste-frontend er vendret inn. Designskillene er tatt inn uten skript, binærer og hooks (se `VENDORED.md`).
- **`fase-3-planlegging`:** `DESIGN.md` og `EXPERIENCE.md` med mockup, `ARCHITECTURE-SPINE.md` (AD-1 til AD-24), krysssjekk (11 retting, 3 kosmetiske), impeccable-critique (29/40, 12 funn tatt inn), 38 stories i 8 epics, og `sprint-status.yaml` (gaten besto).
  - PRD FR-7 er snevret inn til enheten som sendte svarene, fordi den motsa FR-12.
  - Dommeren bruker OpenRouter med `deepseek/deepseek-v4.1-flash`.
- **`epic-1-fundament`** (ligger oppå fase 3): story 1.1–1.5 er ferdige i 22 commits.
  - Innhold: skjelett, design-tokens, innlogging, spill og tilstandsmaskin, sletting og opprydding.
  - Etter 1.5: 264 unit-/integrasjonstester og 44 e2e. Lint og typecheck er rene. Agentene kjørte alt, og orkestratoren kjørte lint, typecheck og unit-testene selv.
- Ingenting er pushet.

### Åpne punkter
- Reviewene av hele epic 1 før PR: `bmad-code-review`, `ponytail-review`, `impeccable` critique/audit/harden.
- Sidetitler per side (WCAG 2.4.2) mangler. Rettes i opprettingsrunden etter epic-reviewene.
- CI er ikke kjørt på GitHub. Push `fase-3-planlegging` og `epic-1-fundament` og sjekk Node 22/26-jobbene.
- PR-rekkefølge: fase 3 først, så epic 1, som er stablet oppå.
- Vercel: installer CLI-en (`npm i -g vercel && vercel login`), og legg inn `DATABASE_URL` (Neon) og `OPENROUTER_API_KEY` i Vercel og i lokal `.env`.
- Epic 7: en av dere kjører `npm run judge:record` med OpenRouter-nøkkelen.
- Godkjenn eller endre teksten på forsiden: «Lag spørsmål om gjengen, samle inn anonyme svar og spill topplista sammen på én skjerm.»
- Daglig cron for opprydding trenger `CRON_SECRET` ved pilot-deploy (story 7.5).
