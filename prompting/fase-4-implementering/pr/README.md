# PR-tekster

Ferdigskrevne beskrivelser for PR-ene, én per branch. Mergerekkefølge (branchene er stablet):

1. `fase-3-planlegging` → `main`
2. `epic-1-fundament`
3. `epic-2-innsamling`
4. `epic-3-lukking`
5. `epic-4-gruppering` (merges tett etter epic 3)
6. `epic-5-gjennomgang`
7. `epic-6-spill`

Hver tekst oppsummerer storiene, reviewene av hele epicen (`bmad-code-review`, `ponytail-review`,
`impeccable`) og hva som ble rettet, slik CLAUDE.md krever.
