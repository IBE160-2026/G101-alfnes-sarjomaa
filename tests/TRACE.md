# Test trace

Maps every Stage 1 FR, and the NFRs the stories so far touch, to the tests or manual checks that prove it. Test titles start with the ID they prove. `tests/unit/trace.test.ts` fails if a Stage 1 FR heading is missing, or if a Stage 1 FR section has no bullet naming an existing file under `tests/` (a test or a manual item) or saying that CI runs it. Bullets that start with "Open" or "Pending", or say "not in CI" or "Open until", do not count.

Each story adds its rows here. An "Open" bullet names a consequence whose proof is not in place yet; every one of them is listed in the SM-1 gate section of `tests/manual/checklist.md`, which says whether SM-1 has passed. The SM-3 anonymity audit is `tests/manual/anonymity-audit.md`.
